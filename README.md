# 影片字幕修订库

本仓库用于整理和记录个人自行修订的影片字幕。字幕按电影、剧集和特典分类，并通过文件名标注作品、语言、字幕类型和修订版本。

## 目录结构

```text
subtitles/
├── movies/
│   └── <影片名> (<上映年份>)/
├── series/
│   └── <系列名> (<首播年份>)/
│       └── Season 01/
└── specials/
    └── <所属作品名> (<年份>)/
```

- **电影**：放入 `subtitles/movies/影片名 (年份)/`。
- **剧集**：放入 `subtitles/series/系列名 (首播年份)/Season 01/`，季数使用两位数字。
- **特典**：放入 `subtitles/specials/所属作品名 (年份)/`，包括 SP、OVA、OAD、NCOP、NCED、PV、MENU、INFO 等内容。
- 标题优先使用正式或常用名称；目录名和字幕文件名中的作品标题保持一致。
- 如果字幕只适配某个具体版本或剪辑版，在文件名中加入版本标记。
- 空目录中的 `.gitkeep` 只用于保留目录；目录开始存放字幕后可以删除对应占位文件。

## 文件命名规范

电影字幕：

```text
<影片名> (<年份>)[.<版本标记>].<语言>.<字幕类型>.v<主版本>.<次版本>.<扩展名>
```

剧集字幕：

```text
<系列名> (<首播年份>).S<季数>E<集数>[.<版本标记>].<语言>.<字幕类型>.v<主版本>.<次版本>.<扩展名>
```

特典字幕：

```text
<作品名> (<年份>).<特典类型><序号>.<语言>.<字幕类型>.v<主版本>.<次版本>.<扩展名>
```

方括号表示可选字段，实际文件名中不要输入方括号。没有版本标记时，省略该字段及其前面的点号。示例：

```text
subtitles/movies/你的名字。 (2016)/你的名字。 (2016).zh-CN.full.v1.0.ass
subtitles/series/寒蝉鸣泣之时 (2006)/Season 01/寒蝉鸣泣之时 (2006).S01E01.zh-CN.full.v1.0.ass
subtitles/specials/寒蝉鸣泣之时 (2006)/寒蝉鸣泣之时 (2006).NCOP01.zh-CN.signs.v1.0.ass
```

### 字段说明

- **语言**：使用 BCP 47 语言标签，如 `zh-CN`、`zh-TW`、`ja-JP`、`en-US`。
- **字幕类型**：`full` 表示完整对白字幕；`forced` 表示仅翻译需要理解的外语对白或画面内容；`signs` 表示仅翻译画面文字、标牌等；`sdh` 表示包含说话人和声音提示的听障字幕。
- **版本标记**：只在字幕明确适配特定剪辑版时使用，例如 `Theatrical`、`DirectorCut`、`Extended`。
- **特典类型**：使用 `SP`、`OVA`、`OAD`、`NCOP`、`NCED`、`PV`、`MENU`、`INFO`、`CM` 等标记；同类内容按 `01`、`02` 顺序编号。
- **修订版本**：首次整理使用 `v1.0`；小幅错字、断句或时间轴修正递增次版本，如 `v1.1`；大幅重译或重新调整时间轴递增主版本，如 `v2.0`。
- **扩展名**：保留实际格式并使用小写，例如 `.ass`、`.srt`、`.ssa`、`.vtt`。

## 字幕上传规范

1. 每个文件夹按作品和年份区分；剧集再按季数分目录。
2. 同一作品的不同语言、字幕类型或剪辑版分别保存为独立文件。
3. 字幕文本使用 UTF-8 编码；上传前确认文件可正常打开，时间轴和样式没有意外损坏。
4. 文件名不要使用 `<>:"/\\|?*` 等 Windows 不支持的字符，也不要用 `final2`、`最新版` 等不明确后缀代替版本号。
5. 可在作品目录中添加 `notes.md`，记录适配的影片版本、时间轴来源和重要修订说明。
6. 仓库只放字幕及相关说明文件，不放影片或音轨文件。

## 上传检查清单

- 作品名称、年份、季数或集数正确。
- 语言、字幕类型、剪辑版和版本号已按规范标记。
- 文件放在对应的电影、剧集或特典目录中。
- 字幕能够打开，时间轴、编码和样式符合预期。
- 修改内容与版本号相符。
